# 数据来源与必要性

这些文件是当前选定的运行配置。不能把“经过重建工程加工”理解为每个字段都由本项目原创。

| 数据 | 来源与使用 |
|---|---|
| serve_app_conf_android.json | 关服前设备配置，242 页/67 partials，经服务端修订；RenderWire 去注解并输出页面配置 |
| serve_preset_data.json | 重建静态骨架；账号、库存、货币和时间由当前玩家状态注入 |
| serve_quest_catalog.json | 原包部分默认字段、本地关卡/数值设计与 Wiki 目录混合 |
| memorial_masterdata.json | JP 纪念版 MasterData、官方样本、推导/默认值及文本补缺；编译期内嵌 |
| unit_battle_behavior.json | 官方样本字段与按武器重建默认值；编译期内嵌 |
| shared/cards | merusuto/data 社区 Wiki/人工快照；数值之外含角色文本与来源字段 |
| unit_roster_manifest.json | 素材名称可用性与 cards 指纹生成的元数据；不是素材本体 |
| SQL 迁移 | 结构与确定性种子，完整历史保留；不是玩家运行库 |

cards 是启动必读数据。DB 同伴模板只覆盖已有同伴行；缺失同伴回退静态目录，魔宠与模板索引仍从 cards 读取。其 SHA256SUMS 与 unit_roster_manifest 的来源指纹须保持匹配。

社区卡牌来源：[merusuto/data](https://github.com/merusuto/data)。目前未核实其明确再分发许可证；来源声明不代替第三方许可。其他混合文件保留 _provenance 等标注，MIT LICENSE 不自动为第三方内容补充授权。

游戏剧本与素材需要使用者自行准备。经验表的社区数值 TSV 为现有全表测试保留；运行使用 Go 常量，源码与 TSV 都保留来源说明。重新生成纪念版表需要额外原始材料，本仓库不包含相应的提取环境。
